About Me

Driven by Curiosity, Defined by Craft

I’m Kymer Oriel Crisostomo, a software developer and creative technologist. I specialize in building full-stack web applications that combine rock-solid backend infrastructure with fast, intuitive user interfaces.

My philosophy is centered around clarity in code and design: before writing a single line of backend logic or UI code, I design low-fidelity structural blueprints and establish clean design tokens. This ensures every product is accessible, responsive, and easy to maintain.

When I'm not coding or designing interfaces in Figma, you'll find me exploring new web standards, optimizing database schemas, and participating in tech communities.
